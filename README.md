# Comparative Genomic Analysis of Antimicrobial Resistance in Klebsiella pneumoniae

## Project Overview

This project investigates antimicrobial-resistance (AMR) genes present in
publicly available Klebsiella pneumoniae genome sequences. Klebsiella
pneumoniae is a bacteria that causes hospital infections and is often
resistant to antibiotics.

## Research Question

Which antimicrobial-resistance genes are present in Klebsiella pneumoniae
genomes, and how do these gene sequences differ between strains?

## Data

Genome sequences will be downloaded from the NCBI database.

## Planned Workflow

1. Select good-quality genomes from NCBI
2. Detect resistance genes in each genome
3. Build a table showing which genes are present in which genome
4. Compare strains and draw a phylogenetic tree (a family tree of the strains)
5. Interpret the patterns

## Tools

- NCBI
- AMRFinderPlus
- Python (pandas, matplotlib)
- iTOL
